# C 逻辑运算符：康奈尔笔记

来源：`programming.md`。示例语言为 C，不是 C++。

## 提示：`||` 与 `|` 有什么区别？

**对应笔记：** `||` 是逻辑或，`|` 是按位或，两者不能互换。

## 提示：逻辑或何时计算右操作数？结果是什么类型？

**对应笔记：** 只有左操作数与零比较相等时，才会计算右操作数。逻辑或的结果类型为 `int`，取值只能是 `0` 或 `1`。

## 提示：短路如何影响下面的 `++count`？

**对应笔记：** 左操作数 `1` 不等于零，因此右侧 `++count` 不会执行。最终 `ok` 为 `1`，`count` 仍为 `0`。

```c
int count = 0;
int ok = (1 || ++count);
/* ok == 1; count == 0 */
```

## 提示：`&&` 与 `||` 谁的优先级更高？

**对应笔记：** `&&` 的优先级高于 `||`。可以用括号明确预期的分组方式。

## 简短总结

C 中的逻辑或 `||` 会短路求值，结果是 `int` 类型的 `0` 或 `1`；不要与按位或 `|` 混用。混合使用 `&&` 和 `||` 时，注意优先级，并用括号明确分组。
